**Author:** Muhammad Ibrahim Zubair  
**Project Type:** Undergraduate Control Systems Project (Bachelor’s Thesis Foundation)  
**Focus:** Nonlinear modeling → State-space representation → Jacobian linearization → Controllability analysis of a magnetic levitation (Maglev) system

## Project Overview

This repository documents the complete mathematical modeling and analysis of a single-axis magnetic levitation system. The work forms the technical foundation for the design of a Model Predictive Controller (MPC) and comparison with a conventional PID controller.

The Maglev system suspends a ferromagnetic object using an electromagnetic force that counteracts gravity. The system is inherently nonlinear and open-loop unstable, making it an excellent benchmark for advanced control techniques.

---

## System Description

### Physical Parameters
| Symbol | Description                        | Value          |
|--------|------------------------------------|----------------|
| \( m \)    | Mass of levitated object           | 0.1 kg         |
| \( z \)    | Air-gap (position)                 | state variable |
| \( i \)    | Coil current                       | state variable |
| \( u \)    | Applied voltage (control input)    | input          |
| \( R \)    | Coil resistance                    | 1 Ω            |
| \( L \)    | Coil inductance                    | 0.05 H         |
| \( k \)    | Magnetic force constant            | calculated     |
| \( g \)    | Gravity                            | 9.8 m/s²       |

Magnetic force:  
\[
F = k \frac{i^2}{z^2}
\]

---

## Governing Equations

**Electrical circuit:**
\[
u = L \frac{di}{dt} + R i
\]

**Mechanical motion:**
\[
m \ddot{z} = mg - k \frac{i^2}{z^2}
\]

---

## Nonlinear State-Space Model

States:
- \( x_1 = z \) (position)
- \( x_2 = \dot{z} \) (velocity)
- \( x_3 = i \) (current)

Input: \( u \) (voltage)

\[
\begin{aligned}
\dot{x}_1 &= x_2 \\
\dot{x}_2 &= g - \frac{k x_3^2}{m x_1^2} \\
\dot{x}_3 &= -\frac{R}{L} x_3 + \frac{1}{L} u
\end{aligned}
\]

---

## Equilibrium Point

At equilibrium (\( \dot{x} = 0 \)):

\[
i_0 = z_0 \sqrt{\frac{m g}{k}}, \quad u_0 = R i_0
\]

Using \( z_0 = 0.05 \) m and \( i_0 = 0.7 \) A:

- \( u_0 = 1.4 \) V  
- Magnetic constant \( k \) calculated accordingly

---

## Linearized State-Space Model

Jacobian linearization about the equilibrium yields:

\[
A = \begin{bmatrix}
0 & 1 & 0 \\
3924 & 0 & -28.03 \\
0 & 0 & -40
\end{bmatrix}, \quad
B = \begin{bmatrix}
0 \\
0 \\
20
\end{bmatrix}
\]

Final linearized model:
\[
\Delta \dot{x} = A \Delta x + B \Delta u
\]

---

## Controllability Analysis

Controllability matrix:
\[
\mathcal{C} = \begin{bmatrix} B & AB & A^2B \end{bmatrix}
\]

Determinant:
\[
|\mathcal{C}| = 6.78 \times 10^6 \neq 0
\]

**Result:** The system is **fully controllable**.

---

## Stability Analysis

The linearized system has the following eigenvalues:

\[
\lambda = \{ +62.64,\ -62.64,\ -40 \}
\]

Because one eigenvalue has a **positive real part** (\( +62.64 \)), the open-loop system is **unstable**.

This is expected for magnetic levitation systems and is the main reason advanced controllers (such as MPC or state-feedback) are required.

An open-loop simulation from a small initial position disturbance (1 mm) confirms that the position error grows exponentially (see plot generated by `open_loop_instability.m`).
